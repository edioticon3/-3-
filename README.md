# -3-
3 ก๊ก 3 เหล่า เราชาวแมวเดอะแก๊ง ส้มจี้ด สมศรี + จิ้มลิ้ม + ชม้อย + ไมเคิล
ก๊ก 1 ผู้มาก่อนกาล (1)ส้มจี้ด แมวพื้นขาวลายส้มตรงหลังและหัวและหาง สายซึน รักนะแต่ไม่แสดงออก ทำเป็นไม่ชอบแค่ครืดให้เสียงดัง เนียนมาใกล้จริงอยากให้ลูบให้กอด ตัวตึงมีศักดิ์เป็นพี่สาวของสมศรี (2) สมศรีแมวลายสลิดเสือ น้องสาวของส้มจี้ด ชอบโวยวาย พูดมาก ขี้บ่น ชอบเถียง ขี้อ้อน และดีดไม่รู้จักเวล่ำเวลา ทั้งคู่เดินทางมาจาก รพ.สงขลา ช่วงที่เขาจะเซตซีโร่ คนใจดีเลยหาบ้านให้และเราได้สิทธิ์นั้นมา ตอนแรกรับมาอยู่บ้านที่ตาก แต่พอแม่เสียไปตอนปี 2564 ก็ย้ายมาอยู่แพร่กับเราปี 2565 ทั้งคู่เกิดประมาณปลายปี 2559 ที่อยู่หลักคือบ้าน โซนห้องแมว เป็นห้องที่ทำขึ้นเพื่อ 2 พี่น้องนี้โดยเฉพาะ มีประตูแมวเพื่อเชื่อมต่อห้องนอนเราโดยตรง เป็นเงินที่ได้จากงานศพแม่เอามาทำห้องให้นางทั้งคู่ ทั้งคู่ไม่รับและไม่เป็นมิตรกับสมาชิกใหม่ล้านเปอร์เซ็นต์
ก๊ก 2 จิ้มลิ้ม เกิดประมาณ ปลายปี2560 รปภ.โรงงาน เพศเมีย สีพื้นขาวมีลายสลดจางๆ พาดกลางหลังและหัว หางม้วนเป็นกลมๆ ดุ๊กดิ๊กๆ อยู่ตรงตูด เหมือนหางกระต่าย ทำตัวเหมือนไบโพล่า อารมณ์เปลี่ยนง่ายแบบสุดขั้ว อ้อนเฉพาะเราและโอมและแม่ ที่เหลือแค่นั่งหายใจก็ผิดแล้วถ้านางอารมณ์ไม่ดีมีกัดมีจกมีสักด่วน ลิ้มเลือกมาอยู่โรงงานด้วยตัวเอง น่าจะชอบการได้มีบ้านใหญ่ๆ อยู่คนเดียวตอนกลางคืน ทำหน้าที่จัดการสัตว์ที่ไม่ได้รับเชิญเช่นหนู นก หรือสัตว์รำคาญอื่น ลิ้มไม่รับสมาชิกเพิ่ม โหมดก้าวร้าวล้านเปอร์เซ็นต์
ก๊ก 3 หนูน้อยผลัดถิ่น (1)ชม้อย เพศเมีย แมวมินิไซส์ ลายสลิดขนทราย ปากมีรอยจุ่มวิปครีม เกิดประมาณเดือน ก.ค.2567 อยู่ดีๆ ก็วิ่งทะเล่อทะล่าเข้ามาหาที่โรงงานช่วงหัวค่ำเมื่อ พ.ย.67 เรารับไว้ทันที น้องขี้โกงที่ไม่ว่าจะถ่ายรูปมุมไหนก็ดูแบ๊วไปหมด ยกเว้นเวลานอน หลับไม่สนสวยมาก ติดไบโพล่ามาจากจิ้มลิ้ม เล่นสนุกได้ทุกเครื่องเล่น ไม่ต้องเสียดายที่จะเปย์เลย (2) ไมเคิล แมวไซส์ใหญ่ เพศผู้ แรกรับคือ พ.ค.68 (เกิด มี.ค.68) แรกรับน้ำหนัก 7 ขีด ผอมโซ หาอาหารไม่เป็น อายุแค่ 3 เดือน เหมือนจะหลงมาแล้วหาทางกลับบ้านไม่ได้ กินน้ำค้างยอดหญ้ากับแมลงประทังชีวิต กลัวคน เราเลยต้องใช้แผนล่อจับ จับได้ก็พาเข้าบ้าน ไมเคิลเป็นแมวส้ม ลายสลิดเสือชัดมาก หางยาว โครงใหญ่ แบบ what's Michel เป๊ะ ปัจจุบันทะลุ 6 โลไปแล้ว ถูกเลี้ยงดูโดยชม้อย ทั้งคู่สนิทกันใน 3 วัน ทุกวันนี้อาศัยอยู่ที่บ้าน แต่ไม่ถูกกับก๊ก 1 จึงมีห้องส่วนตัวอยู่ฝั่งตะวันออกของบ้าน ชอบคอนโดที่มีหลุมใส ชอบเขี่ยลูกบอลบนราง พลังงานเยอะเพราะยังเด็กทั้งคู่
**ทุกคนทำหมันแล้ว และรับวัคซีน Rabies และหัดรวม พร้อมถ่ายพยาธิ ทุกปี
โซนนิ่งที่บ้าน ก๊ก 1 เลี้ยงกึ่งปิด กลางวันได้สิทธิ์ครองพื้นที่ในบ้านทั้งหมด รวมโซนนอกบ้านด้วย แต่คงสำรวจพอใจแล้วจึงไม่ได้ออกบ้านบ่อย ส่วนใหญ่จะอยู่เฝ้าบ้าน นอนตากพุงอยู่ระเบียงเป็นต้น ครองเนื้อที่หมดยกเว้นห้องชม้อยไมเคิล  กลางคืนหลังสี่ทุ่มต้องกลับไปนอนห้องแมว (ห้องตัวเอง) เจอกันอีกทีคือเช้าถัดไป
โซนนิ่งที่บ้าน ก๊ก 2 ไมเคิลกับชม้อย เลี้ยงปิดล้านเปอร์เซ็นต์ กลางวันอยู่ในห้องตัวเอง กลางคืนได้บ้านทั้งหลังยกเว้นห้องแมว ได้สิทธิ์นอนกับเราด้วย
กฏสำคัญของบ้านคือไม่ว่ากลางวัน จิ้มลิ้ม สมศรี ส้มจี้ดจะไปเที่ยวไหน เย็นต้องกลับบ้าน/พื้นที่ตัวเอง และกลางคืนห้ามออกนอกบ้านเด็ดขาด
